# SQL Queries for Rockbuster Stealth Analysis

This repository contains SQL queries developed for the **Rockbuster Stealth LLC** project. These queries analyze critical business data to support Rockbuster’s transition from a physical movie rental service to an online streaming platform.

## Project Overview
Rockbuster Stealth LLC, a global movie rental company, is preparing to launch an online video streaming service to compete with platforms like Netflix and Amazon Prime. This analysis focuses on answering essential business questions, including:
- Which movies generate the most and least revenue?
- How do rental durations vary across customer segments?
- What are the geographic and demographic trends among customers?
- How do sales and rental patterns differ by region?

## Key Questions and Objectives
The Rockbuster Stealth Management Board has posed a series of business questions to inform their 2020 company strategy. The SQL queries in this repository aim to address the following key questions:
- **Movies**: Which movies contributed the most and least to revenue gain?
- **Rental Durations**: What was the average rental duration for all videos?
- **Customer Demographics**: Which countries are Rockbuster customers based in?
- **High-Value Customers**: Where are customers with a high lifetime value located?
- **Sales Variations**: Do sales figures vary between geographic regions?

## Dataset
The dataset is sourced from Rockbuster's internal systems and includes:
- **Movies**: Titles, categories, and performance metrics.
- **Customers**: Demographics and geographic details.
- **Payments**: Rental transactions and revenue.
- **Rentals**: Duration and frequency data.

The data is stored in a relational PostgreSQL database with structured tables representing customers, payments, films, and rental activity.
